# Como contribuir

Obrigado por querer melhorar a Aliança IA Consciente. Este repositório é o lugar onde o manifesto, os compromissos e os guias evoluem.

## O que é bem-vindo

- Correções de texto, links quebrados e fontes desatualizadas.
- Novas evidências (pesquisas, estudos) que reforcem ou contestem um compromisso.
- Exemplos práticos para a seção "Na prática" de um compromisso.
- Fluxos de IA testados para a biblioteca (veja o [compromisso 3](compromissos/03-produtividade-com-metodo.md)).
- Casos que não funcionaram. Eles ensinam tanto quanto os que funcionaram.

## Como propor

1. Para mudanças pequenas (texto, link), abra um pull request direto.
2. Para mudanças em um compromisso ou no manifesto, abra antes uma *issue* explicando o problema e a proposta. Mudanças no texto dos compromissos são aprovadas pelo comitê da aliança.

## Regras para contribuições

- **Cite as fontes.** Todo número ou afirmação de pesquisa precisa de link para a fonte, de preferência a original.
- **Nada de dados pessoais ou confidenciais.** Exemplos usam dados fictícios ou anonimizados (veja o [compromisso 7](compromissos/07-dados-protegidos.md)).
- **Seja claro e curto.** Frases diretas, voz ativa, sem jargão desnecessário.
- **Sinalize o uso de IA.** Se a contribuição foi escrita com apoio relevante de IA, diga isso na descrição do pull request e confirme que você revisou e concorda com cada frase. É o [compromisso 4](compromissos/04-a-ia-nao-fala-por-nos.md) aplicado aqui.

## Modelo de descrição de pull request

```markdown
## O que muda

## Por quê

## Fontes

## Uso de IA
- [ ] Não usei IA
- [ ] Usei IA para: ______ e revisei todo o conteúdo
```
